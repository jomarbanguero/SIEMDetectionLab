# 🔐 Azure Honeypot & SIEM Detection Pipeline

**Microsoft Azure | Microsoft Sentinel | KQL | Log Analytics | Threat Detection | Cloud Security**

## 📌 Project Overview

This project demonstrates the development of a cloud-based security monitoring environment using Microsoft Azure and Microsoft Sentinel.

I deployed a Windows 10 virtual machine as a honeypot to observe unauthorized authentication activity, investigate Windows security logs, and centralize security telemetry using Azure Log Analytics.

I then used Kusto Query Language (KQL) and geolocation enrichment to analyze suspicious activity and visualize its geographic distribution in Microsoft Sentinel.

### Project Highlights

- 28,000+ recorded attack attempts
- Activity associated with 9+ countries
- Windows security event investigation
- Centralized security logging
- Microsoft Sentinel SIEM integration
- KQL-based analysis
- Geographic attack visualization

## 📊 Results and Findings

During the monitoring period, the honeypot recorded more than **28,000 attack attempts**, with source IP data associated with **at least nine countries**.

The collected events demonstrated how an exposed cloud environment can receive significant volumes of suspicious authentication activity.

By centralizing the logs and analyzing them through Microsoft Sentinel, I gained practical experience interpreting security telemetry and visualizing suspicious activity.

These findings reflect observed events, not necessarily successful intrusions or unique attackers.
